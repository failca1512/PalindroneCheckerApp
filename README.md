## UC3: Palindrome Check Using String Reverse

### Goal:

### Flow:
1. Reverse string using a for loop
2. Compare original and reversed
3. Display result

### Key Concepts:
- Loop (for loop)
- String immutability
- String concatenation (+)
- equals() method

String
